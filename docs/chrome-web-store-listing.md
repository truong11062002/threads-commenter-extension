# Chrome Web Store Listing

## Title

Threads AI Commenter

## Summary

Generate on-brand Threads replies in your voice with AI tones and saved comment strategies.

## Description

Generate on-brand AI replies directly inside Threads, using your saved voice and comment strategy.

Threads AI Commenter helps creators, founders, indie hackers, marketers, and growth teams reply faster without sounding generic. Open a Threads reply box, click the inline AI button, choose a tone, and the extension generates a contextual reply you can use right away.

What it does:

- Saves **Your voice** so replies can match your natural style, energy, vocabulary, and boundaries.
- Saves your **Threads comment strategy** so generated replies follow the angle you want.
- Offers 12 tone options: Simple, Friendly, Funny, Insightful, Curious, Relatable, Contrarian, Supportive, Expert, Visionary, Analytical, and Meme.
- Includes 3 strategy templates: **Spark Reply**, **Value Drop**, and **Hot Take**.
- Formats replies to feel more human and mobile-native, with clean spacing between thoughts.
- Works directly inside the Threads reply composer, so you can stay in flow.

Strategy templates:

- **Spark Reply**: open question hook for pulling real engagement.
- **Value Drop**: add value plus a soft CTA to build authority.
- **Hot Take**: contrarian angle plus credibility to stand out.

The extension is designed for people who want to show up consistently in replies, build a recognizable voice, and turn more posts into useful conversations.

Privacy notes:

- A generated device ID is stored locally.
- Your saved voice and strategy are stored by the Threads AI Commenter API for that device.
- Threads post text is sent to the API only when you generate a reply.
- No login, logout, or external analytics are included.
